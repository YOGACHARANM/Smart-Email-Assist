# Smart Email Assistant Extension

A Full-Stack AI-powered Email Assistant built using Spring Boot, React, and Spring AI to help users generate professional email replies directly inside Gmail.

## Features

* Generate AI-based email replies
* Multiple professional reply tones
* Gmail integration using Chrome Extension
* Fast and user-friendly interface
* Context-aware responses using Google Gemini API

## Tech Stack

### Frontend

* React
* HTML
* CSS
* JavaScript

### Backend

* Java
* Spring Boot
* Spring AI
* REST APIs

### AI Integration

* Google Gemini API

### Tools

* Chrome Extension
* Git & GitHub
* Maven

## How It Works

1. User opens Gmail
2. Chrome Extension adds AI reply option
3. Email content is sent to Spring Boot backend
4. Gemini API generates a smart reply
5. AI response is displayed instantly in Gmail

* Built a full-stack AI application
